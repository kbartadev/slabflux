# SlabFlux Core: Dispatcher (`dispatcher.hpp`)

## 1. Architectural Overview
The heart of the Cartesian routing system. The dispatcher converts raw byte streams and `tagged_pointer` envelopes into typed C++ function calls with strictly enforced causal ordering.

## 2. Zero-Cost SFINAE Dispatch
Utilizing the topological typelists generated by the Meta Compiler:
- It evaluates event types sequentially in branchless instruction blocks.
- It completely bypasses virtual dispatch and dynamic RTTI (`dynamic_cast`).
- The logic executes the perfect intersection of base-class methods and leaf-class overrides in place.

## 3. Context Vault Injection
Seamlessly unpacks necessary state structures from the injected `context_vault` and forwards them to the business logic handler entirely at compile-time.
