# SlabFlux I/O: Hardware Shaper (`slabflux/io/hardware_shaper.hpp`)

## 1. Architectural Justification
Prevents switch-level micro-burst packet loss by enforcing strict Inter-Packet Gap (IPG) tolerances directly at the hardware layer.

## 2. Hardware Implementation Directives
- **Nanosecond Pausing**: Uses CPU pause instructions (`TPAUSE`, `_mm_pause`) instead of OS `sleep()` to idle the thread with sub-microsecond precision.
- **RDTSC Bounds**: Continuously polls the `__rdtsc()` counter to ensure outbound network transmissions are physically separated by exact nanosecond intervals, protecting downstream Arista/Cisco switch buffers from overflow.

## 3. Burst Smoothing
Buffers high-velocity responses generated by algorithmic models and releases them into the DPDK/io_uring TX ring at a mathematically perfectly spaced cadence.
