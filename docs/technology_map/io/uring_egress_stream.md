# SlabFlux I/O: io_uring Egress Stream (`slabflux/io/uring_egress_stream.hpp`)

## 1. Architectural Justification
The `uring_egress_stream` is the transmission counterpart for connection-oriented sockets. It resolves the problem of high-frequency micro-writes (common in HFT responses) saturating the network stack by aggressively coalescing outbound events into unified `io_uring` requests.
Transmitting data over connection-oriented TCP streams often suffers from micro-writes and the TCP Nagle algorithm. The `uring_egress_stream` aggregates outbound deterministic states and bypasses standard socket bottlenecks using asynchronous scatter-gather I/O.

## 2. Hardware Implementation Directives
- **Vectorized Stream Aggregation**: Instead of pushing independent packets via `IORING_OP_SEND`, it harvests the wait-free egress conduit for all pending outbound signals and bundles them into an `iovec` array, dispatching a single `IORING_OP_WRITEV` into the Submission Queue. This neutralizes the latency penalty of TCP Nagle's algorithm at the application layer.
- **Non-Temporal Buffer Protection**: The egress stream processes pointers allocated by the compute core. After the network controller completes the DMA transfer, the egress module releases the memory back to the NUMA-local allocator pool using explicitly cache-bypassing operations, preventing outbound networking from polluting the L1 compute cache.
- **Partial Write Handling**: If the kernel TCP window shrinks mid-transmission (a partial CQE result), the `uring_egress_stream` calculates the exact byte-offset remainder and re-links the unresolved tail of the `iovec` array into the next SQE, maintaining strict chronological message integrity.
- **Scatter-Gather Batching**: Converts multiple outbound SPSC state pointers into a contiguous `iovec` array. It submits a single `IORING_OP_WRITEV` SQE, instructing the kernel to transmit the scattered memory blocks as a unified TCP segment.
- **Wait-Free Submissions**: Uses an isolated SQPOLL thread. The outbound execution path simply drops the vector array into the shared memory ring and advances the atomic tail, never blocking on kernel network buffer availability.
- **Backpressure Awareness**: Integrates with the completion queue (CQE) to track TCP window limits. If the kernel flags an incomplete write, it transparently shifts the remaining offset pointers without re-copying the payload.

## 3. Deterministic Decoupling
Like its datagram equivalent, this module never executes algorithmic logic. It is a pure hardware orchestrator that translates the deterministic sequence of outbound state mutations into a reliable POSIX stream.
## 3. Pipeline Integration
Functions as the final transmission node for TCP-based gateways (like REST APIs or FIX engines). It continuously drains the outbound `network_conduit` generated by the `branchless_engine` and flushes it to external peers.
