# SlabFlux Net: Demux Gateway (`demux_gateway.hpp`)

## 1. Architectural Overview
The `demux_gateway` is the absolute border boundary between the raw, untyped network ingress streams (e.g., bytes arriving via AF_XDP) and the strictly typed, C++ compiled `pipeline` routing matrix. It performs O(1) protocol resolution and injects the typed event into the deterministic execution core.

## 2. O(1) Tagged Pointer Resolution
Traditional object-oriented demultiplexing relies on reading packet headers, invoking `switch/case` statements, and calling virtual functions (dynamic dispatch), which shatters the CPU's instruction pipeline.

The `demux_gateway` utilizes the `tagged_pointer` architecture:
- When an event is generated by an I/O thread, its 16-bit Type ID is bitwise-packed directly into the unused upper bits of its 64-bit memory address.
- Upon reaching the `demux_gateway`, the demuxer extracts the Type ID via a single bitwise shift (`ptr >> 48`).
- It uses this integer as a direct array index into an unrolled function-pointer jump table, instantly recovering the strictly-typed C++ object without a single branch instruction or virtual table lookup.

## 3. Pipeline Fusion
Once the type is resolved, the gateway invokes the bound `pipeline.dispatch()`.
- The macro-registered `context_association` guarantees that the correct environmental Vault is seamlessly passed alongside the event.
- The event drops flawlessly into the Cartesian Dispatch Matrix, navigating the `unroll_ebases` and `unroll_hbases` SFINAE topologies exactly as defined by the user's `proof.md` In-Place Axioms.

## 4. Sovereign Security Constraints
The Gateway does not blindly trust the I/O layer.
- **Integrity Validation**: It verifies the 64-byte `alignas` boundaries and evaluates any embedded `sovereign_signal` CRC32 checksums.
- **Hardware Traps**: If a corrupted frame attempts to cross the boundary into the compute domain, the gateway halts it and redirects the payload to the `error_arbiter`, preserving the chronological sanctity of the AI/Trading models.
